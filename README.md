# Helicopter Chinook for Minecraft Bedrock Edition

The Helicopter Chinook is an open source project that adds a realistic helicopter model to Minecraft Bedrock Edition. This project includes a detailed 3D model of the helicopter, custom animations for the rotors and doors, and a crafting recipe to create the helicopter in-game. The helicopter can be ridden by players and features realistic physics, including the ability to hover and move in all directions.

## Install

1. Download the `helicopter_chinook.mcpack` file from the GitHub repository.
2. Open Minecraft Bedrock Edition.
3. Go to the "Add-Ons" section in the settings menu.
4. Click on the "Add-On" button and select the downloaded `helicopter_chinook.mcpack` file.
5. Enable the add-on and start a new world or reload the current world to apply the changes.

## Use

1. Craft the Helicopter Chinook using the following recipe:
   - I I
   - R D R
   - I I
   Where I is an Iron Ingot, R is Redstone, and D is a Diamond.
2. Place the crafted Helicopter Chinook in your inventory.
3. Right-click to place the Helicopter Chinook on the ground.
4. Right-click the Helicopter Chinook to ride it.
5. Use the WASD keys to control the helicopter's movement.
6. Press the Space key to ascend and the Shift key to descend.
7. Press the E key to open or close the helicopter's door.
